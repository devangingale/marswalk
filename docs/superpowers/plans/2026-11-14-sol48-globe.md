# Sol-48 Globe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the approved Sol-48 globe design: Plan, Walk and Visor on a CesiumJS Mars globe with science layers, clock and history, current conditions, site-finder, walker and rover routing, pace and daylight, warnings, night contingency, SOS and relay, simulated hardware links, and a sun-adaptive theme.

**Architecture:** Two tracks. Track A (Mac) builds the Cesium app in `app/src/globe/` and the screens. Track B (this laptop) builds pure, tested logic modules in `app/src/lib/` and data in `pipeline/` → `data/globe/` and `data/sites/`. Track A consumes Track B through the interfaces below. MapLibre files are deleted from git in the task that replaces them; a local copy lives in `archive/maplibre-app/` (not in git).

**Tech Stack:** CesiumJS 1.146.0 (engine 26.4.0, widgets 16.3.0 pinned), React 19, Vite 8, TypeScript, pmtiles 4.5.0, vitest; Python 3.14 venv with rasterio, numpy, pytest, spiceypy (pinned when added).

**Spec:** `docs/superpowers/specs/2026-11-14-sol48-globe-design.md` (and `2026-11-14-cesium-migration-design.md` for renderer details). Research inputs: `docs/research/*.md` (in progress on the Mac).

## Global Constraints

- All distances, slopes and areas from the local-metre frame in `app/src/lib/grid.ts` (Mars radius 3396190 m), never from Cesium geodesics.
- Per-site height offset (Cesium Mars minus bundle elevation): Gale +73.76 m, Jezero -70.92 m (spike); measured again at load and compared.
- `VITE_CESIUM_ION_TOKEN` only in `app/.env.local`; never committed or logged. Cesium ion credit always visible.
- Palette (approved): ice blue to white, radiation yellow (reserved), dust ochre to rust, thermal inertia magenta, minerals teal-green, site score green, caves violet, terrain grey, temperature cool-to-warm (charts and its own layer only); insolation coral, surface pressure teal, crustal field olive, unit diversity slate to sand.
- Visual bar: design tokens only; no gradients, glows, emoji, filler, quotation marks, decorative icons or repeated tags; text contrast at least 4.5:1 in both themes; works at 1440x900 and 1024x768 on Gale and Jezero.
- No invented thresholds: values come from `docs/research/` or are labelled, editable assumptions.
- Never mention the earlier prototype in commits or files.
- Done for every task: `npx tsc -b`, `npm run build`, `npx vitest run` pass in `app/`; pytest passes for pipeline work; screenshots in `<worktree>/.shots/` for UI tasks.
- Commits only; the orchestrator pushes and opens PRs; nothing merges to `main` without Dev.

## Review Focus

1. Sol with no sunset or no sunrise at high latitude (polar day or night): sun functions return explicit `null` events and the pace module reports "no daylight window" instead of NaN times. (B1, B2 tests.)
2. Route that revisits a stop or crosses itself: fork detection must not create forks at every crossing; only where legs share then diverge. (B3 tests: crossing legs produce zero forks; out-and-back detour produces exactly one fork.)
3. Ion unreachable or token missing: globe falls back to offline mode with the baked basemap and site layers; planning still works. (A2 test of `initCesium` offline path; A10 manual check with the token unset.)
4. Relay queue during a long gap with no pass: items keep order and nothing is dropped; SOS stays first even if it is created after many queued items. (B4 tests.)
5. Theme switch during an active warning: theme change is deferred until the warning is acknowledged. (A8 test of `nextTheme`.)
